React.js

資管115級 李景臣

課程簡介

目前許多大型網站/服務的前端 Web 平台，
包含 Facebook、Youtube、Netflix 使用 React 進行架 設。
本課程著重在介紹該主流框架的概念，並在實作中帶領大家從 0 開始學會用 React 寫出小專 案。
該課程適合熟悉 HTML，CSS，Javascript 知識，以及了解前後端如何互動的同學參與。
