活動摘要：深度學習

張耀仁講師 | 深度學習與卷積神經網路

本次活動將以「深度學習與卷積神經網路」為核心，結合 Blooket 趣味競賽與 Kaggle 平台實戰。首先透過 Blooket 互動遊戲，快速檢測學員對於神經網路基本元件（如 Linear Regression,CNN、Transformer、Loss Function 等）的觀念掌握。隨後進入 Kaggle 實戰環節，學生將化身為 AI 訓練師，針對特定的影像資料集進行模型調優與參數對決。活動旨在模擬真實的數據科學競賽流程，測驗學生對模型擬合、泛化能力的理解，並提升在有限算力下的實戰解題實力。

活動摘要：React 網頁設計

李景臣講師 | React前後端系統建置

本次活動將以「React前後端系統建制」為核心進行實戰。第一階段將以Blooket趣味競賽讓大家進行理論知識的競技，以了解學員們對整體React框架的熟悉度。第二階段將以實作賽進行比較，學員們將挑戰如何在有限的時間内以React搭配node.js建制一個簡易前後端系統，以了解學員本學期的學習成果。

題目：

當前端使用 fetch 呼叫 API 取得回應物件 (Response) 後，通常需要使用哪一個內建方法將其轉換為可讀的 JSON 格式？

選項：
  • A. .toString( )
  • B. JSON.stringify( )
  • C. .json( )
  • D. JSON.parse( )

正確答案：C

解析：`.json()` 是 Response 物件的內建方法，專門用來將回應內容解析為可用的 JavaScript 物件。

題目：

Adam 優化器相比基本的 SGD，主要優點是什麼？

選項：
  • A. 訓練速度一定更快
  • B. 自動調整每個參數的學習率，收斂更穩定
  • C. 引入了動量(momentum)的概念，避免訓練卡住
  • D. 模型準確率一定更高

正確答案：B

解析：Adam 結合了動量與自適應學習率的機制，能針對每個參數自動調整學習率，使訓練過程收斂更穩定。
